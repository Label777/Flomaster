# Как добавить игру в каталог

Каталог — один файл: `web/src/catalog/games.ts`. Каждая игра — объект в массиве `GAMES`; порядок в массиве = порядок карточек на главной. Жанры для фильтра собираются из игр автоматически.

## 1. HTML5-игра, которая лежит на сайте (самый простой путь)

1. Положите игру в `web/public/games/<id>/` (точка входа — `index.html`). Все её файлы должны быть рядом: сайт работает в режиме cross-origin isolated, и сторонние скрипты/шрифты с чужих CDN загрузиться не смогут.
2. Добавьте запись в `GAMES`:

```ts
{
  id: 'snake',                          // латиница, цифры, дефис → адрес #/g/snake
  title: 'Змейка',
  tagline: 'Классика: ешь, расти, не врезайся',
  description: ['Первый абзац описания.', 'Второй абзац.'],
  genres: ['Аркада', 'Классика'],
  players: '1',
  platform: 'any',                      // 'desktop' — только клавиатура и мышь
  badges: ['Без установки'],
  status: 'ready',                      // 'soon' — карточка видна, «Играть» неактивна
  launch: { kind: 'iframe', src: 'games/snake/index.html' },
  cover: { from: '#2c4a3b', to: '#0f1814', glyph: GLYPH_TARGET }, // или image: 'games/snake/cover.webp'
},
```

Готовый пример — `web/public/games/reflex/` («Реакция»).

## 2. HTML5-игра на другом сайте

`launch: { kind: 'iframe', src: 'https://example.com/game/' }` — встроится в плеер сайта. Работает, только если тот сайт разрешает встраивание (нет `X-Frame-Options: DENY` / `frame-ancestors`). Фрейм грузится с атрибутом `credentialless`, поэтому в Chrome и Edge чужие игры без своих COEP-заголовков открываются; в Firefox и Safari такой фрейм может не загрузиться — тогда используйте `kind: 'external'`.

`launch: { kind: 'external', href: 'https://example.com/game/' }` — кнопка «Играть ↗» откроет игру в новой вкладке.

## 3. Игра со своей страницей запуска

Как Counter-Strike 1.6: `launch: { kind: 'route', href: '#/play' }` и своя страница в `web/src/pages/`, зарегистрированная в `PAGES` в `web/src/main.ts`. Нужна для игр, которым требуется загрузчик файлов, настройки или сеть.

## Обложка

- `cover.image` — путь к картинке в `web/public/` (лучше 16:9, `.webp`, до ~200 КБ).
- Без картинки обложка рисуется из градиента `from → to` и знака `glyph` (статичная SVG-разметка в `games.ts`).

## Юридически

- Добавляйте только игры, которые вы вправе распространять: свои, с открытой лицензией (укажите её в `THIRD_PARTY_NOTICES.md`) или те, где игрок, как в CS 1.6, использует **свою** копию файлов.
- Не используйте чужие логотипы и арт в обложках без разрешения. Для игры с товарным знаком заполните поле `legal`.
- `scripts/check-no-valve-files.sh` в CI не пропустит в репозиторий файлы игр Valve.
