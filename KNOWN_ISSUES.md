# KNOWN_ISSUES

Что не работает в браузере или не удалось проверить, и как это обойти. Пункты, помеченные **[НЕ СВЕРЕНО]**, написаны по документации upstream без доступа к исходникам и должны быть проверены до публичного запуска.

## 1. [НЕ СВЕРЕНО] Протокол WebRTC-сигналинга с `yohimik/cs-web-server`

Путь WebSocket (`CS_SIGNAL_PATH`, по умолчанию `/websocket`), формат сообщений (`{type:'offer'|'answer'|'candidate', …}`) и параметры data channel взяты из описания архитектуры upstream, а не из кода. Если онлайн-подключение зависает на «Сигналинг…», сверьте `web/src/net/protocol.ts` с upstream-клиентом:

```bash
scripts/verify-upstream.sh            # скачает upstream и покажет нужные фрагменты кода
```

Обход на время расследования: upstream-клиент образа открывается напрямую на `http://<IP>:27016` при временной публикации порта (только для проверки, без `valve.zip`).
